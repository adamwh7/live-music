# Roland TR-8S — Changelog

Newest at the top. One entry per change pushed to the device.

## 2026-11-21

- Tested and working: Start/Stop from the MIDI Captain. MIDI Captain MIDI OUT → TR-8S MIDI IN. Captain page3 "TR8S TEST": footswitch A = `[realtime][start]`, B = `[realtime][stop]`. TR-8S UTILITY:MIDI set to Rx Start/Stop ON, Sync = AUTO. It only works on AUTO. No other sync setting works. The tempo is set on the TR-8S, and the footswitches only start and stop it.
